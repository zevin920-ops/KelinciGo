🐰 KelinciGo

Website pemesanan transportasi kereta wisata.

KelinciGo adalah website untuk membantu pelanggan melakukan pemesanan perjalanan dengan mudah dan melihat status pesanan secara online.

✨ Fitur

- Form pemesanan perjalanan
- Pemilihan jumlah kereta
- Kapasitas 24 penumpang per kereta
- Perhitungan total kapasitas otomatis
- Penyimpanan pesanan menggunakan Firebase
- Kode pesanan untuk pelacakan
- Halaman tracking pesanan
- Dashboard admin untuk mengelola pesanan

🚂 Kapasitas Kereta

- 1 kereta memiliki 6 bangku
- Setiap bangku berisi 4 penumpang
- Kapasitas setiap kereta adalah 24 penumpang
- Jumlah kereta dapat dipilih dari 1 hingga 50

🛠️ Teknologi

- HTML
- CSS
- JavaScript
- Firebase Firestore
- Firebase Authentication
